# Security

No released application is currently supported; this repository is at the documentation/setup stage. Version support and a tested private reporting route must be established before public application release.

Do not include vulnerabilities, personal birth dates, credentials or exported private settings in public issues. Until a private reporting route is configured, open an issue requesting a private security contact without describing the vulnerability; the maintainer will arrange a channel before receiving details. No response-time guarantee is established.

Local storage is browser-specific and is not a backup. The reviewed product scope has no backend, account or sync; do not introduce personal-data network requests, telemetry or diagnostic logging. Hosting access logs and any future data-handling changes need explicit documentation.
