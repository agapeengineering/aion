# Product overview

The [R1 specification](../requirements/web-release-specification.md) owns the product rationale, release scope, requirements and verification mapping. Keep detailed behavior there rather than maintaining duplicate definitions.

Aion makes finite time visible through a quiet life-in-weeks calendar. It is free and bilingual. Each person chooses a lifespan assumption. Guest calendars stay on the device. An optional verified account lets a person save their calendar and use it on another device.

Web ships first with manual PNG export, followed by native releases with supported widgets and wallpaper integrations. Real usable releases define progress; each advertised platform needs its own build, verification and distribution evidence.

The public web release includes email-code sign-in, profile sync and account management. Daily and weekly email reflections remain deferred. [Account release record](../releases/web-accounts.md) · [R2 specification](../requirements/backend-release-specification.md)
