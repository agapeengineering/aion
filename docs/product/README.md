# Product overview

The [R1 specification](../requirements/web-release-specification.md) owns the product rationale, release scope, requirements and verification mapping. Keep detailed behavior there rather than maintaining duplicate definitions.

Aion makes finite time visible through a quiet life-in-weeks calendar. It is free, local-only and bilingual. Users choose their own lifespan assumption; the application does not predict life expectancy.

Web ships first with manual PNG export, followed by native releases with supported widgets and wallpaper integrations. Real usable releases define progress; each advertised platform needs its own build, verification and distribution evidence.

The [accepted R2 amendment](../requirements/backend-release-specification.md) adds optional verified accounts, settings sync and opt-in daily/weekly email reminders while retaining complete local guest use. R2 is an implementation baseline, not a shipped feature claim.
