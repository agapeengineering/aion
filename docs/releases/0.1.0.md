# Aion web 0.1.0

Date: 2026-10-17. Channel: early web release. Maintainer: Agape Engineering.

## Included

A complete local-only bilingual web calendar: editable birth date/90-year default horizon, lived/current/future week overview and exact interval explorer, seven lived/remaining units with a ticking approximate countdown, pause/resume, remaining-figure visibility, local settings/edit/reset/tab synchronization, original phrases, privacy explanation and local phone/desktop PNG export.

Source is MIT licensed; bundled fonts retain OFL notices. There are no accounts, backend, cloud sync, product analytics, advertising or paid features. Static hosting is Cloudflare Workers Static Assets. Native widgets and automatic wallpapers are separate future releases.

## Verification and publication

The [verification record](../testing/web-verification.md) describes 82 unit checks, the shared fixture audit and 33 HTTPS-staging browser checks. Final deployment/version/rollback evidence is recorded after publication; planned steps are not claimed as completed here.

Public source, requirements and setup are self-contained. Private planning systems are not required to follow this release.

## Known limitations

- This is an early release pending the product-owner walkthrough, physical iPhone/Safari and VoiceOver/zoom validation. Engine automation is not physical-device certification.
- Input is date-only; subday totals are approximate and can jump with DST, manual clock or timezone changes. A horizon is a chosen assumption, never a prediction.
- A new browser/device starts fresh. Re-enter the two inputs; no server backup or account recovery exists.
- PNG export is static and manually applied; it does not update as time passes. Native ambient behavior remains unimplemented.
- Offline works after resources are loaded; an offline first visit/PWA installation is not promised.
- There is no 24/7 uptime or human-response guarantee.
